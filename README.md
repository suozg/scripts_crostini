# scripts_crostini

Набор личных Bash-, Python- и C-скриптов для рабочего окружения **Crostini/Linux на ChromeOS**. Репозиторий объединяет утилиты для запуска приложений, DWM/dwmblocks, работы с файлами и документами, резервного копирования, шифрования, контроля дисков и сети, а также небольшие пользовательские программы.

Скрипты создавались для конкретного окружения и содержат локальные пути, имена дисков и пользовательские настройки. Перед использованием проверьте конфигурацию внутри каждого файла.

## Важно перед использованием

- Это не единый устанавливаемый пакет, а коллекция независимых инструментов.
- Часть скриптов рассчитана на Crostini и пути `/mnt/chromeos/removable/...`.
- Некоторые файлы используют пути пользователя `/home/alex320388` или `$HOME` — замените их на свои.
- Скрипты `backup`, `encrypt_files`, `decrypt_files` и `encrypt_2_zip` изменяют или удаляют файлы. Сначала запускайте их на копиях данных.
- `check_usb_disk.sh`, `chk_net.sh` и `check_ports.py` используют `sudo` и системные команды.
- В проекте нет общего менеджера зависимостей или автоматических тестов.

## Быстрый порядок настройки

### 1. Склонировать репозиторий

```bash
git clone https://github.com/suozg/scripts_crostini.git
cd scripts_crostini
```

### 2. Сделать исполняемые файлы запускаемыми

```bash
find . -maxdepth 1 -type f \( -name '*.sh' -o -name 'backup' -o -name 'encrypt_files' -o -name 'decrypt_files' -o -name 'encrypt_2_zip' -o -name 'searchdocs.sh' \) -exec chmod +x {} +
find dwm lf my_tasks radio -type f \( -name '*.sh' -o -name 'battery' -o -name 'disk' -o -name 'mpvdwm' -o -name 'netstatus' -o -name 'watch_caps' \) -exec chmod +x {} + 2>/dev/null || true
```

### 3. Проверить и исправить пути

В первую очередь проверьте:

- `backup` — пути SD Card, KINGSTON, Google Drive и каталогов `~/WORK`, `~/awards`;
- `7087_start` — путь к бинарному файлу DRS и базе `7087.db`;
- `awardstart` — путь к `awardswx` и `awards_v4e.db`;
- `disk_rclone.c` — имя пользователя и точки монтирования rclone;
- `dwm/autostart.sh` — домашний каталог и установленные программы;
- `lf/lfrc` — пути к программам и пользовательские команды.

### 4. Установить зависимости по назначению

Базовый набор для большинства Bash-скриптов:

```bash
sudo apt update
sudo apt install -y bash coreutils findutils grep sed awk util-linux procps \
  imagemagick poppler-utils img2pdf zip unzip gpg rclone trash-cli \
  libreoffice pandoc python3 python3-pip gcc make
```

Python-скрипты:

```bash
python3 -m pip install --user pandas
```

Для DWM окружения дополнительно могут потребоваться `dwm`, `dwmblocks`, `dmenu`, `st`, `picom`, `xsettingsd`, `xkb-switch`, `xset`, `xsetroot`, `dunst`, `notify-send`, `i3-nagbar`, `lf`, `nvim`, `mpv` и `xclip`.

## Рекомендуемый порядок использования

### Повседневный запуск окружения

1. Запустить X-сессию/DWM.
2. Подключить `dwm/autostart.sh` или корневой `autostart.sh` к автозапуску.
3. Проверить работу блоков DWM через скрипты из `dwm/`.
4. Запускать приложения через `awardstart`, `7087_start` и другие launcher-скрипты после проверки путей к бинарным файлам и базам.

### Работа с документами

1. Подготовить изображения или документы.
2. При необходимости обработать изображения через `image_process.sh` или `resize_px_H740.sh`.
3. Собрать изображения в PDF через `pix2pdf.sh`.
4. Для уменьшения размера PDF использовать `pdf_jpg_700_pdf.sh` или `shrink_pdf.sh`.
5. Для объединения офисных документов использовать `merge_docx.py`.
6. Для поиска текста в офисных, PDF, текстовых и GPG-файлах использовать `searchdocs.sh`.

### Работа с данными AWARDS

1. Подготовить два CSV-файла.
2. Сравнить список всех людей со списком награждённых через `awards_diff_list.py`.
3. Запустить AWARDS через `awardstart` или DRS через `7087_start`.
4. Для резервного копирования использовать `backup` после проверки подключённых носителей и настроек rclone.

### Шифрование и расшифровка

- Для рекурсивного шифрования файлов GPG: `encrypt_files <каталог>`.
- Для расшифровки `.gpg`-файлов: запустить `decrypt_files` из каталога с файлами.
- Для создания ZIP-файлов с паролем: `encrypt_2_zip`.
- Для синхронизации рабочих каталогов и резервного копирования: `backup`.

Не объединяйте эти операции с `backup`, пока не проверили, какие каталоги будут изменены и какие файлы будут удалены.

## Каталог скриптов

### Запуск приложений AWARDS/DRS

| Файл | Назначение | Использование |
|---|---|---|
| `awardstart` | Запуск скомпилированного AWARDS с базой `awards_v4e.db` | `./awardstart` |
| `7087_start` | Запуск DRS с базой на SD Card | `./7087_start` |
| `nn_start` | Launcher для другого локального приложения/сценария | Проверить пути и запустить `./nn_start` |
| `normalizer` | Пользовательский launcher/утилита нормализации | Проверить содержимое перед запуском |

Launcher-скрипты выводят индикатор через `xsetroot`, показывают ошибку через `dunstify` и очищают индикатор при завершении.

### Документы, изображения и PDF

| Файл | Назначение | Пример |
|---|---|---|
| `merge_docx.py` | Объединяет `.docx`, `.odt`, `.doc`, `.rtf` через LibreOffice и Pandoc | `python3 merge_docx.py merged.odt` |
| `image_process.sh` | Приводит изображения к размеру 1240×1754, поворачивает альбомные и сохраняет в `output/` | `./image_process.sh` |
| `resize_px_H740.sh` | Масштабирует изображения до высоты 740 px | `./resize_px_H740.sh` |
| `pix2pdf.sh` | Создаёт PDF из JPG/JPEG/PNG; поддерживает штамп через `-s` | `./pix2pdf.sh` или `./pix2pdf.sh -s stamp.pdf` |
| `pdf_jpg_700_pdf.sh` | Растровает PDF, уменьшает изображения до высоты 700 px и собирает новый PDF | `./pdf_jpg_700_pdf.sh input.pdf` |
| `shrink_pdf.sh` | Дополнительное уменьшение PDF | Проверить параметры перед применением |
| `pdf_2_jpg` | Конвертация PDF в изображения | Проверить `--help`/содержимое |
| `readword.sh` | Чтение/обработка документов Word | Проверить зависимости |
| `searchdocs.sh` | Поиск фразы в TXT, CSV, LOG, Office, PDF и GPG-файлах | `./searchdocs.sh 'фраза' /path/to/folder` |
| `convert_nakaz_vysluga.sh` | Обработка документов, связанных с приказами/выслугой | Проверить входные файлы и пути |
| `macros_libreoffice-1` | Макрос/скрипт для LibreOffice | Использовать только в настроенном LibreOffice |

`searchdocs.sh` вводит пароль GPG один раз, расшифровывает файлы во временный каталог `/dev/shm`, ищет текст и удаляет временные файлы после завершения.

### CSV и AWARDS

| Файл | Назначение | Пример |
|---|---|---|
| `awards_diff_list.py` | Находит людей из общего CSV, отсутствующих в CSV награждённых; нормализует ПІБ и кодировки раскладок | `python3 awards_diff_list.py all.csv rewarded.csv -o without_awards.csv` |
| `my_tasks/` | Отдельное приложение для задач и заметок | См. раздел ниже |

`awards_diff_list.py` использует `pandas`, автоматически определяет столбец ПІБ и поддерживает UTF-8/CP1251.

### Шифрование и резервное копирование

| Файл | Назначение |
|---|---|
| `encrypt_files` | Рекурсивно шифрует файлы каталога GPG и удаляет исходники после успешного шифрования |
| `decrypt_files` | Расшифровывает все `.gpg` в текущем дереве каталогов |
| `encrypt_2_zip` | Создаёт отдельный парольный ZIP для каждого файла в `protected/` |
| `backup` | Интерактивный цикл: транслитерация имён, синхронизация `awards`/`WORK` на SD через rclone и отправка на Google Drive/KINGSTON |
| `sdcard.sh` | Работа с подключённой SD Card |
| `cpdf` | Вспомогательный бинарный/launcher для работы с PDF и штампами |

Перед `backup` настройте rclone remote `now_crypt:` и `gdrive:`, подключите нужные носители и проверьте значения переменных в начале файла.

### Проверка системы, дисков и сети

| Файл | Назначение | Запуск |
|---|---|---|
| `battery.sh` | Заряд батареи, статус зарядки и уведомления | `./battery.sh` |
| `disk.sh` | Использование `/`, `/tmp` и количество файлов в корзине | `./disk.sh` |

| `chk_net.sh` | Сводная проверка сокетов, процессов, сервисов, cron, маршрутов и журналов | `sudo ./chk_net.sh` |

### DWM и dwmblocks

Каталог `dwm/` содержит автозапуск и блоки статусной строки: батарея, диск, сеть, радио, буфер обмена, задачи, раскладка, календарь, выбор цвета и запуск приложений. Основные файлы:

- `dwm/autostart.sh` — запускает `xsettingsd`, `watch_caps`, раскладку, тему, `picom` и Neovim agenda;
- `dwm/battery.sh`, `dwm/disk.sh`, `dwm/net_speed.sh` — блоки состояния;
- `dwm/radio.sh`, `dwm/mpvdwm` — радио и название текущей композиции;
- `dwm/sbtsks.sh` — задачи в статусной строке;
- `dwm/toggle_layout.sh`, `dwm/translator.sh` — раскладка и перевод;
- `dwm/dwmblocks/` — исходники/конфигурация dwmblocks;
- `dwm/dmenu/`, `dwm/st-flexipath/`, `dwm/pinentry-dmenu/` — связанные компоненты рабочего окружения;
- `dwm/C_version/` и бинарные файлы без расширения — скомпилированные или альтернативные версии утилит.

Подключайте блоки в конфигурации dwmblocks, например:

```c
{ "", "cat /tmp/dwm-radio-status", 0, 15 },
```

### Приложение задач: `my_tasks/`

Каталог содержит несколько реализаций приложения задач:

- `my_tasks.py` — Python-версия;
- `my_tasks.c` и `my_tasks_org.c` — C-версии;
- `my_tasks_add.sh` — добавление задачи;
- `my_tasks_edit.sh` — редактирование задачи;
- `my_tasks` — готовый исполняемый файл;
- `read_me.md` — локальная заметка по приложению.

Перед сборкой C-версии проверьте исходники и зависимости:

```bash
cd my_tasks
gcc -O2 my_tasks.c -o my_tasks
```

### Файловый менеджер `lf/`

`lf/` — конфигурация файлового менеджера:

- `lfrc` — основные привязки и команды;
- `colors`, `icons` — оформление;
- `pv.sh` — предпросмотр;
- `readoc.sh` — предпросмотр/чтение офисных документов;
- `rclone.conf.gpg` — зашифрованная конфигурация rclone.

Установка конфигурации зависит от версии `lf`; обычно файлы копируют в `~/.config/lf/`, но перед копированием проверьте пути в `lfrc`.

### Радио: `radio/`

`radio/` содержит управление MPV-радио и демон `mpvdwm`, который записывает текущую композицию в `/tmp/dwm-radio-status`. Подробная инструкция находится в [`radio/README.md`](radio/README.md).

```bash
cd radio
# пример сборки демона
gcc -O2 mpvdwm.c -o mpvdwm
sudo cp mpvdwm /usr/local/bin/
./mpvdwm
mpv --no-video --input-ipc-server=/tmp/mpv-radio-socket 'URL_РАДИО'
cat /tmp/dwm-radio-status
```

### Vim/Neovim и заметки

`vimwiki/` содержит заметки и конфигурацию Neovim (`init.lua`) по Bash, DWM, Git, `lf`, Vim и установке пакетов. Это справочные материалы, а не самостоятельная программа.

## Автозапуск

Корневой `autostart.sh` — общий вариант для X-сессии: блокировка повторного запуска, загрузка `~/.profile`, раскладка, тема и `picom`.

`dwm/autostart.sh` — вариант для DWM с дополнительным запуском `xsettingsd`, `watch_caps`, agenda в Neovim и приложений DWM.

Не запускайте оба варианта одновременно, пока не убедились, что это не создаёт дубликаты процессов.

## Перемещение файлов

Сейчас файлы оставлены на исходных местах намеренно: конфигурации `dwm`, `lf`, `radio`, `my_tasks` и launcher-скрипты используют относительные и абсолютные пути друг к другу. Безопаснее сначала поддерживать порядок через этот README, а физическое перемещение выполнять отдельным изменением с одновременным обновлением:

- `dwm/autostart.sh`;
- `lf/lfrc`;
- `radio/README.md` и radio-скриптов;
- launcher-файлов `awardstart`, `7087_start`, `nn_start`;
- пользовательских unit-файлов systemd.
